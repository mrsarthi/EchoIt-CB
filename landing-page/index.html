Core Capabilities

Self-Sovereign Identity

Authenticated cryptographically via local wallet signatures. No email, no phone numbers, no centralized credential registries.

Immutable Usernames

Claim custom aliases permanently mapped to your wallet signature in the signaling directory. Zero moderation, zero censorship.

End-to-End Encryption

Uses cryptographic keys generated client-side. Double ratchet guarantees forward secrecy and post-compromise security.

Local-First Storage

All conversations and cryptographic enclaves reside on your hardware. Relays process ephemeral packets and store nothing.

Optimized Group Receipts

Read receipts route directly and exclusively back to the message author. Eliminates chat metadata leaks and heavy data synchronization overhead on group channels.

Cryptographic Protocol

Echo implements a high-performance communication pipeline that combines TweetNaCl cryptography with client-side sqlite enclaves. Every message payload is locked on-device before transport.

  • X25519 DH key bundles with XSalsa20-Poly1305 symmetric lockboxes
  • Signaling server abstracts routing coordinates without accessing keys
  • Mutex-locked send queue ensures zero-drop reliability during offline states
